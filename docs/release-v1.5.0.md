## Pause Continued 1.5.0 for SPT 4.1.x

Continuation of [PAUSE by netVnum](https://sp-mod.com/mod/2046/pause), with the author's permission.

Updated for SPT 4.1.x (tested on 4.1.6). **Does not work on SPT 4.0.x.**

### Changes
- Updated for SPT 4.1, where the game's internal class names changed
- Fixed camera zoom after unpausing, including when aim is released during the pause
- Extra safety checks around the raid timer and bots
- New install folder: `BepInEx\plugins\rejzbihai-Pause\`

### Installation
Extract `rejzbihai-Pause-1.5.0.zip` into your SPT folder.
If you have the original Pause, delete `netVnum.Pause.dll` first: Pause Continued does not load while it is installed. Your pause key is imported automatically.
